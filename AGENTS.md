# Agent Guidelines

## Development principles
- Use TDD for all new features and fixes.
- Maintain 100% test coverage (lines, branches, functions, statements).
- Keep implementations small, readable, and maintainable (KISS/YAGNI).
- Prefer English for all project artifacts and code.
- Update documentation for every feature change.

## Architecture & quality
- Keep files focused and avoid large, complex modules.
- Refactor proactively if files grow too large or responsibilities blur.
- Measure test coverage and code quality metrics on every change.

## Documentation
- Keep `README.md` current with setup, scripts, and workflow details.
- Document recurring architectural or coding requirements here.

## Workflow
- Trunk-based development: work on a branch off `main` and open a PR back to `main`.
